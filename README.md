# Postman API Testing Project

API testing project created using Postman.

## APIs Tested

- GET API Status
- GET Single Product
- GET All Products
- POST Create New Order

## Testing Covered

- Status code validation
- Response body validation
- API key authentication
- JSON response parsing
- Collection variables
- Dynamic variable handling
- Postman test scripts
- Request chaining

## Test Results

8/8 automated verification tests passed.

## Tools

- Postman
- REST API
- JavaScript
- Git/GitHub

## How to Run

1. Import the Postman collection.
2. Add your API key to the collection/environment variable.
3. Configure the base URL.
4. Run the requests.
5. Run "Verify your work" to execute the validation tests.
